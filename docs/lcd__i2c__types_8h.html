Definições de tipos, estruturas e enumerações da biblioteca LCD.

Autor
Tiago Henrique dos Santos/Ciência Elétrica
Data
2026

Este arquivo contém as definições essenciais para a abstração de hardware, incluindo o handle principal do objeto LCD e ponteiros de função para integração com diferentes drivers I2C.

Definições dos tipos

◆ lcd_i2c_write_ptr

typedef int8_t(* lcd_i2c_write_ptr) (uint8_t slave_addr, uint8_t data)

Definição da assinatura da função de escrita I2C (Ponteiro de Função).

O usuário deve fornecer uma implementação que realize a escrita de um único byte no barramento I2C para o endereço especificado.

Parâmetros
slave_addrEndereço I2C do dispositivo escravo (PCF8574).
dataByte de dado a ser transmitido.
Retorna
int8_t Deve retornar 0 para sucesso ou um valor negativo para erro.

Enumerações

◆ lcd_backlight_t

enum lcd_backlight_t

Estados possíveis para o controle da luz de fundo (Backlight).

O valor associado corresponde ao bit de controle enviado ao PCF8574.

Enumeradores
LCD_BACKLIGHT_OFF 

Backlight desligado

LCD_BACKLIGHT_ON 

Backlight ligado (Bit 3 do PCF8574)

◆ lcd_status_t

enum lcd_status_t

Status de retorno das funções da biblioteca.

Utilizado para verificar o sucesso ou falha de operações de inicialização e comunicação.

Enumeradores
LCD_OK 

Operação concluída com sucesso

LCD_ERROR 

Falha genérica na operação

LCD_BUSY 

O dispositivo ou barramento está ocupado

LCD_TIMEOUT 

Tempo de espera excedido durante a comunicação
