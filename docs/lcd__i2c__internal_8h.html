Este arquivo contém as declarações das funções de suporte que gerenciam a comunicação de baixo nível, como o envio de nibbles e a geração de pulsos de clock (Enable) para o controlador HD44780.

Funções

◆ lcd_pcf8574_pulse_enable()

void lcd_pcf8574_pulse_enable ( lcd_t * handle,
uint8_t data )

Gera o pulso de "Enable" (transição High -> Low) no pino EN.

Essencial para que o controlador do LCD capture os dados presentes nos pinos de dados (D4-D7). Implementa os delays necessários para o setup time.

Parâmetros
handlePonteiro para a estrutura de configuração do LCD.
dataO byte atual que está sendo enviado (com o bit EN em nível alto).
Observação
Utiliza tempos de subida (2us) e descida (40us) para garantir a estabilidade.

Função utilitária para enviar 8 bits, dividindo-os em dois nibbles.

Realiza o fracionamento do byte em parte alta (Most Significant Nibble) e parte baixa (Least Significant Nibble) para transmissão sequencial.

Parâmetros
handlePonteiro para a estrutura de configuração do LCD.
valueO byte completo de 8 bits a ser transmitido.
modeDefine o estado do pino Register Select (RS).

◆ lcd_send_nibble()

void lcd_send_nibble ( lcd_t * handle,
uint8_t nibble,
uint8_t mode )

Envia 4 bits (nibble) para o LCD através do expansor I2C.

Como a interface com o LCD é de 4 bits, esta função prepara o byte combinando os dados, o estado do pino RS e o estado do Backlight.

Parâmetros
handlePonteiro para a estrutura de configuração do LCD.
nibbleOs 4 bits de dados (devem estar alinhados nos bits superiores D4-D7).
modeDefine o propósito do envio: 0 para Comando (RS=0) ou 1 para Dado (RS=1).
